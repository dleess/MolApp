## Codebase Patterns
- The iPadOS app builds through `MolApp.xcodeproj` with shared scheme `MolApp`; use the README `xcodebuild` command with `CODE_SIGNING_ALLOWED=NO` for simulator verification.
- Keep `MoleculeViewerView` viewport-first: the primary viewer should be the back layer in a full-screen `ZStack`, with controls added as overlays instead of sidebars that resize the viewport.
